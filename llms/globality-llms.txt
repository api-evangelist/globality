# Globality

> Globality is an AI-driven enterprise sourcing and procurement platform that helps large organizations run sourcing events, manage tail spend, and reduce costs through automated, guided workflows and an AI advisor. It integrates with SAP Ariba, SAP Fieldglass, and Coupa via prebuilt connectors and exposes a developer API and webhooks for syncing sourcing, contract, and spend data. Backed by the SoftBank Vision Fund. ISO/IEC 27001:2022 certified, with SOC 2 and GDPR compliance.

This llms.txt was generated by the API Evangelist enrichment pipeline from the repository's apis.yml and probed artifacts. Globality does not publish a public OpenAPI or API reference; the developer API and webhook technical docs are gated (PDF / customer login).
